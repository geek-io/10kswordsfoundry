# Typography

Body and controls: Inter, bundled from https://github.com/google/fonts/tree/main/ofl/inter with its OFL license in assets/fonts/Inter-OFL.txt.

Section headings and character names: Times New Roman, then Times/serif. Major headings: ITC Benguiat, Benguiat ITC, Benguiat, then Times New Roman/Times/serif.

Times New Roman and ITC Benguiat are referenced as client-installed fonts, not redistributed. No Benguiat font file was available in the workspace or installed font directories. A supplied webfont with permission to distribute can be bundled later for consistent display across players. Installing a font only on the Foundry server does not install it on players’ computers.
